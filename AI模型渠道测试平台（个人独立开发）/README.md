# AI 模型渠道测试平台

个人独立开发的 AI 模型渠道测试工具。本目录提供 Windows、Mac 分发包及脱敏用户手册。

| [Mac 分发包](./AI模型渠道测试平台_Mac.zip) | [直接下载安装包](https://media.githubusercontent.com/media/Reyon-1/qa-testing-portfolio/main/AI%E6%A8%A1%E5%9E%8B%E6%B8%A0%E9%81%93%E6%B5%8B%E8%AF%95%E5%B9%B3%E5%8F%B0%EF%BC%88%E4%B8%AA%E4%BA%BA%E7%8B%AC%E7%AB%8B%E5%BC%80%E5%8F%91%EF%BC%89/AI%E6%A8%A1%E5%9E%8B%E6%B8%A0%E9%81%93%E6%B5%8B%E8%AF%95%E5%B9%B3%E5%8F%B0_Mac.zip)，下载后解压使用 |

ZIP 安装包需要下载后解压，不能当作网页打开。若文件页面显示无法预览，请使用上表的“直接下载安装包”。

两个压缩包使用 Git LFS 存储。通过 Git 克隆时，需要安装 Git LFS 并拉取大文件；直接下载时，请使用对应文件页面的下载入口。

分发包中的渠道密钥为空，需要按手册配置自己的测试地址、模型和密钥。测试会产生真实模型调用时，请自行确认测试范围和额度。
