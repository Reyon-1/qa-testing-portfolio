## 脱敏方式

按字段白名单重新生成发布材料，不复制整份原始Apifox项目或环境。端/场景/文档ID改为匿名编号，业务路径按一致映射泛化；账号、密码、Token、上游Key、内网域名/IP、端口、真实组织、联系人、资源ID、发票及业务金额明细、机器码和私有目录均不发布。

公开金额仅为隔离场景设计参数；统计、执行日期、断言数量、通过/失败数量保留原值。界面不含业务响应截图。

## 复用方式

用Python运行`核验工具/核验成果.py`可离线核对表格、场景目录、JUnit与汇总一致。命令不访问测试环境。实际执行的Apifox命令形态：

```powershell
apifox test-suite run <SUITE_ID> --project <PROJECT_ID> --branch main --environment <ENV_ID> --reporters json,junit --out-dir <LOCAL_REPORT_DIR>
```

实际项目ID、环境、凭据及OCR/下载辅助均由私有执行环境管理。公开目录不包含生产可运行的认证配置，也不将未导出的当前定时任务配置当成已验证交付。
