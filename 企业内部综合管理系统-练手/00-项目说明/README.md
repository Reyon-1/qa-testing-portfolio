# 企业内部综合管理系统测试实践项目

## 项目说明
本项目围绕传统企业内部综合管理系统开展测试实践，整理了功能测试用例、接口测试集合、数据库验证脚本和测试报告，适用于组织人事、权限配置、基础业务配置与审计管理等场景。

本资料为测试实践项目，当前覆盖基础管理与审计能力，不包含财务核算、薪资管理等未纳入本次测试范围的模块。

## 测试范围
- 用户管理模块（增删改查、状态切换、搜索筛选）
- 角色权限模块（角色分配、权限配置、状态管理）
- 登录认证模块（登录、验证码）
- 菜单配置模块（菜单树、新增/删除菜单）
- 部门管理模块（部门树、新增/删除部门）
- 字典管理模块（字典类型、字典数据）
- 参数设置模块
- 日志审计模块（操作日志、登录日志）


## 测试工具
- **功能测试**：手工测试 + Excel 用例管理
- **接口测试**：Postman（接口关联、环境变量、断言）
- **数据库验证**：MySQL（多表关联、聚合查询、数据一致性验证）
- **缺陷管理**：Excel 缺陷跟踪表
- **版本管理**：Git / GitHub

## 测试结论
- 用例总数：70条
- 覆盖模块：9个
- 接口测试：20个
- 发现问题：3项体验优化建议
- 核心功能运行稳定，交互体验层面有优化空间
- 通过 MySQL 数据验证确认前后端数据一致性
